# Optional Obsidian setup

Obsidian is a human interface over the project memory; it is not the authority and is not required by the AI workflow.

## Setup

1. Install Obsidian from its [official distribution](https://obsidian.md/download).
2. Choose **Open folder as vault**.
3. Select `docs/project-memory/` in your cloned repository.
4. Keep writing ordinary Markdown links so documents remain useful on GitHub and in other editors.

The repository ignores `.obsidian/` by default because workspace layout and plugin state are machine-specific. A team may later commit a reviewed subset of Obsidian configuration through an accepted decision.

## Safety

- Review community plugins before enabling them; they execute with access to vault content.
- Do not sync project memory to an unapproved account or storage provider.
- Do not create a second vault containing copied project memory.
- Resolve edits through Git like any other documentation change.
